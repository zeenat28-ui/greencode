## 💡 Pro Tips

1. **Judges spend 2-5 minutes per project initially**
   - Make it EASY to understand what you built
   - Clear description, live demo link, video

2. **AWS service usage must be OBVIOUS**
   - Don't make judges hunt for "how did they use Bedrock?"
   - List it explicitly in README

3. **Open source is a PLUS, not required**
   - Shows confidence in your code
   - Demonstrates real engineering (tests, docs, CI/CD)

4. **Profile privacy is fine**
   - Judges look at the repo, not your profile
   - Public repo + private profile = common and acceptable
