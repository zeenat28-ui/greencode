# Alexa+ add-on manifest

`addon.json` follows the Alexa+ MCP quickstart schema (`manifestVersion`
`1.0`) and is validated in `tests/test_alexa_compliance.py` against the
published field constraints (name ≤30, shortDescription ≤123,
fullDescription ≤4000, 3–4 examplePhrases ≤200 each, HTTPS URLs, all six
icon sizes, a 600x900 carousel image, `integrations[].type = "MCP"`,
endpoint `type = "HTTPS"`).

## URL wiring (live)

Every URL in `addon.json` is currently filled from a running tunnel and was
verified over the public internet (all → 200, `/mcp` → 401 without token):

| addon.json field | Served by |
|---|---|
| `endpoints.default.uri` | MCP transport at `/mcp` |
| `privacyPolicyUrl` → `/privacy`, `termsOfUseUrl` → `/terms` | pages from `pages/` |
| icon + carousel URIs → `/assets/*.png` | static mount, generated by `scripts/gen_alexa_icons.py` |

The server builds these routes only when `alexa/pages/` and `alexa/assets/`
exist, so a bare deployment stays MCP-only.

**Quick tunnels get a new domain on every start.** After restarting
`scripts/start_mcp_remote.ps1`, update the `addon.json` URLs to the printed
`https://…trycloudflare.com` domain (or use a Cloudflare named tunnel with a
stable hostname — recommended before `alexa-ai deploy`). The tunnel domain
must be in `GREENCODE_MCP_ALLOWED_HOSTS`; the start script does that
automatically, which is what keeps the transport from answering **421** to
every public request.

Prove the live state at any time:

```powershell
python check_mcp_alexa.py --url https://<tunnel>.trycloudflare.com --token $env:GREENCODE_MCP_TOKEN
```

## Before `alexa-ai deploy`

`alexa-ai` installs from Amazon's **private** CodeArtifact registry
(`npm install -g @alexa-ai/cli` after `aws codeartifact login`, see
[Set Up Your Development Environment](https://developer.amazon.com/docs/alexaplus/add-ons/set-up-your-development-environment.html))
and authenticates with `alexa-ai configure` (Login with Amazon in a browser).
Both need your Amazon developer / AWS credentials — the one step this repo
cannot perform for you.

## Deploy

```powershell
alexa-ai deploy          # validates addon.json and registers the endpoint
```

Redeploy whenever the MCP tool list changes: "Alexa+ refreshes tool
information only on deployment."
