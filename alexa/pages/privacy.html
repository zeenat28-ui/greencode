GreenCode Privacy Policy

Effective 2026-10-07 · applies to the GreenCode Alexa+ add-on and MCP server.

What we collect

GreenCode analyses source code for energy efficiency. The code you submit is processed to produce an audit result and is not stored, indexed, or shared beyond that request. The MCP server keeps no user accounts and no per-user profiles.

What the server logs

The self-hosted server records operational logs (timestamps, request status, latency) for reliability. These contain no source code and no identity that links a request to an Amazon account.

Third parties

Carbon grid intensity is fetched from Electricity Maps (or a public fallback) for the region you name. Your submitted code is not sent to that provider. LLM-based refactoring, when you invoke refactor_code, sends the snippet to the configured provider (for example Amazon Bedrock); this is disclosed in the tool description.

Your choices

Do not submit code you are not permitted to process. To remove this add-on from Alexa+, disable it in the Alexa app's Connected Apps list.

Contact

Questions: open an issue at github.com/zeenat28-ui/greencode.
