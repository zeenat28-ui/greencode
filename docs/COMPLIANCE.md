# GreenCode Standards Alignment & Technical Evidence Reference

> **Important Disclaimer:** GreenCode provides engineering-level calculations, provenance metadata, and SHA-256 hash-chained audit logs to assist engineering and sustainability teams. GreenCode is **not** independently certified under SOC 2 Type II, ISO 14064-1, CSRD, or SEC audit regimes.

## Technical Implementation Matrix

| Standard / Specification | Technical Aspect | GreenCode Code Implementation |
| :--- | :--- | :--- |
| **Green Software Foundation (GSF)** | Software Carbon Intensity (SCI) v1.0 | Implements $SCI = \frac{(E \times I) + M}{R}$ in [`app/sci.py`](../app/sci.py) across static scans, dynamic sandbox runs, and MCP tool calls. |
| **GHG Protocol (Scope 2)** | Operational Electricity Emissions | Multiplies measured or modeled energy (kWh) by regional grid carbon intensity ($g\text{CO}_2\text{e/kWh}$) in [`app/sci.py`](../app/sci.py) and [`app/reports/esg_report.py`](../app/reports/esg_report.py). |
| **GHG Protocol (Scope 3)** | Embodied Hardware Amortization | Amortizes server manufacturing carbon over runtime duration and lifespan in [`app/sci.py`](../app/sci.py) and [`app/calibrated_energy.py`](../app/calibrated_energy.py). |
| **ESG / CSRD / SEC Export Schemas** | Structured Carbon & Cost Summaries | Exports JSON, CSV, and printable HTML summaries via [`app/reports/esg_report.py`](../app/reports/esg_report.py) and [`app/reports/exports.py`](../app/reports/exports.py). |
| **Tamper-Evident Audit Logging** | Cryptographic Hash Chaining | Links audit records with SHA-256 (`prev_hash` $\rightarrow$ `record_hash`) in [`app/audit_logs.py`](../app/audit_logs.py) and [`app/pipeline/ledger.py`](../app/pipeline/ledger.py). |

## Provenance & Verification Endpoints
Every energy and carbon figure generated by GreenCode carries explicit provenance so estimates are never confused with physical measurements:
1. **Audit Trail Integrity Check:** `GET /api/reports/audit-logs/{org_id}/verify` and `GET /api/pipeline/ledger/verify` re-compute the SHA-256 chain from genesis (`0000...0000`) and flag any modified record.
2. **Energy Measurement Provenance (`app/energy_sensors.py`):**
   - `measurement_is_hardware: true` when read from Linux RAPL (`/sys/class/powercap`), Scaphandre, `perf`, or battery discharge sensors.
   - `measurement_is_hardware: false` (`measurement_method: "model"`) when estimated via TDP / SPECpower curves on hosts without hardware counter passthrough.
3. **Grid Intensity Provenance (`app/sci.py`):**
   - Reports `intensity_source_tier` (`primary_official`, `customer_key`, `free_dataset`, or `static_matrix`) and `is_live: bool`.
