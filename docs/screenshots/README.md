# Screenshots Guide

## Required Screenshots for README

Upload these screenshots to `docs/screenshots/` and reference them in README.md:

### 1. Dashboard Main View
- File: `dashboard-main.png`
- Shows: Clean interface, "Run Scan" button, empty state
- Size: 1920x1080 or 1280x720
- **How to capture:** Open https://greencode-teal.vercel.app, click Demo Login, take screenshot

### 2. Scan Results
- File: `scan-results.png`  
- Shows: Violations panel with energy metrics, severity badges
- **How to capture:** After running a scan on sample code

### 3. AI Refactoring Panel
- File: `ai-refactoring.png`
- Shows: Original code, refactored code side-by-side, energy savings
- **How to capture:** Click "Generate Fix" on a violation

### 4. Voice Interface
- File: `voice-interface.png`
- Shows: Microphone button, voice command being processed
- **How to capture:** Click microphone icon, speak command

### 5. Energy Metrics Card
- File: `energy-metrics.png`
- Shows: SCI score, carbon emissions, energy consumption
- **How to capture:** Zoom into the metrics cards after scan
